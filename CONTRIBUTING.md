# Contributing to NotVisuals

Development priority: **visual quality → optimize without losing quality → version compatibility**. Discuss substantive changes through issues and PRs, and include real Minecraft testing evidence where applicable.

## Copyright and license rules

- Original source code, shaders, Python and technical definitions are contributed under **GPL-3.0-only**, unless a compatible file-specific license is approved.
- Original artwork, textures, sky atlases, media and icons are contributed under **CC BY-NC-SA 4.0**, only if the contributor can grant those rights.
- Contributors **retain copyright**; there is no automatic transfer, CLA or additional commercial relicensing grant.
- Any import/adaptation must identify upstream author, exact source URL/revision, license and notices. Third-party resources cannot be submitted as if authored by NotVisuals.
- Never remove upstream notices or copy Minecraft assets without applicable rights.
- Commercial exception requests for an outside contributor's CC art must come from **that rightsholder**.

## Pull request checklist

- [ ] State which changed files are source code, artistic media or third-party material.
- [ ] Include proof of origin and licensing for every external file.
- [ ] Run validators and build checks; attach screenshots or logs for visual changes.
- [ ] Keep attribution, file-level notices, and pre-existing license requirements.
- [ ] Check [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md) before official R20 release changes.

Read [LICENSING.md](LICENSING.md) and [TRADEMARKS.md](TRADEMARKS.md).
