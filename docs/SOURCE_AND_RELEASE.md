# NotVisuals — source tree and Modrinth releases

The GitHub project is **source code**, not a ready-to-use Minecraft resource pack.

## Structure

| Path | Purpose |
| --- | --- |
| `src/pack/pack.mcmeta`, `src/pack/pack.png`, `src/pack/assets/` | Source for the installable pack |
| `source/aurora_sky/sun_atlas/` | Reproducible original artwork chunks with hash verification |
| `scripts/` | Deterministic builder, validation, shader and licensing tests |
| `docs/`, `CREDITS.md`, `LICENSE*` | Documentation and license notices |
| `dist/` | Git-ignored build output; not published in GitHub Actions |

Minecraft expects a root `pack.mcmeta` when it scans ZIP resource packs. The GitHub source archive intentionally does not have that structure; users cannot drag its archive into resourcepacks and obtain a working pack. The `scripts/build_pack.py` release process reconstructs the right ZIP layout, including license and attribution files.

**Official user download:** https://modrinth.com/resourcepack/notvisuals

- Keep the full source under GitHub for reproducibility and contributions.
- Build local test ZIPs and inspect them before any publication.
- Use `python3 scripts/build_pack.py --release` only once license checks, final R19 source import and real Minecraft QA are satisfied.
- Do not attach installable ZIPs to GitHub Releases or publish CI artifacts; GitHub's autogenerated source archives remain available.
- Upload the final signed-off installable ZIP to Modrinth separately.

**Distribution limitation:** this is *not DRM*. Under GPLv3, compatible MIT terms and CC BY-NC-SA 4.0, third parties can exercise the licensed redistribution rights. You cannot prevent legitimate rebuilding of the source pack, nor impose a blanket ban on redistributing covered material. Modrinth-first is a recommendation and official release channel, not an exclusive legal right.

**Important R19 status:** the 724-file R19 artifact (41 shader files, 41 pipeline passes, upstream MIT assets from Animated Ore and Water Lilies) is newer than the source snapshot currently on this GitHub branch. Do not identify this old candidate source as complete R19 until those exact files and notices have been imported and validated.
